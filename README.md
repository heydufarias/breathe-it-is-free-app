## Modes

Three breathing patterns to pick from, each built around a different need.

**Relax** - *5s Inhale · 5s Exhale*<br>
Equal, slow inhales and exhales. That steady rhythm is what helps the body settle down.

**Focus** - *4s Inhale · 4s Hold · 4s Exhale · 4s Hold*<br>
Box breathing, four equal phases. Counting through all four gives people's attention one simple thing to track, which is what keeps it from wandering.

**Sleep** - *4s Inhale · 7s Hold · 8s Exhale*<br>
The 4-7-8 pattern, where the exhale runs almost twice as long as the inhale. That imbalance is what slows things down enough to wind down before bed.

## Stack

- **React 19 + TypeScript**: UI and type safety.
- **Vite**: dev server and build tool.
- **Tailwind 4**: utility-first styling.
- **Framer Motion**: transitions and micro interactions.
- **React Three Fiber / Three.js**: the 3D breathing animation.
- **i18next**: translations (En / Pt-br).
